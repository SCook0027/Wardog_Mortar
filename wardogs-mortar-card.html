Help

WARDOGS mortar card, a Rivenword Productions html created for WARDOGS. Prompted by SCook using Grok. The maps will need some work but are fairly accurate. The center is not always in the same place but the coordinates don't change.

Map sheets
Choose Bakurani, Ozeti, or Zestafona. The sheet loads from the folder this page is hosted in.
Ozeti uses ozeti-map.png. Bakurani uses bakurani-map.png. Zestafona uses zestafona_map.png, then zestafona-map.png if that is missing.
Center X and Center Y, with Top X and Top Y, set the combat circle. The circle moves between matches. The grid coordinates do not.
Frame left X, frame top Y, and span are fixed per map. A saved card cannot change them.
Coordinates are X, then Y. One grid square is 100 m. X grows east. Y grows north.

Mortar and targets
Mortar position is Grid X, Grid Y, and a name. The mortar is the green dot, with its name under it.
Add a target with a name, Grid X, and Grid Y. It joins the solution list and gets a red dot with its name under it.
Leave the name blank and click Add target for a temporary read. It shows Bearing, Range, and Elevation in the Add a target panel, and drops a black plus. It is not added to the list.
Right-click the sheet. The window shows X, then Y. Add Target with a name drops a red dot. Name it from or here to move the mortar to that point. Name it center to set the combat center. Leave the name blank to show the same temporary read.
Moving the mortar, from the boxes or from the sheet, refreshes every solution, including the blank-name read.

Solutions
Each row shows bearing in degrees and a compass direction, range in meters, elevation in mils, and a range call.
Working range is 132 m to 675 m, from the community L81 table. A longer shot still shows its range, in red. Flat ground only.
Solutions sort by target name.

Save, export, and load
Save and Load keep the card in this browser, one card per map. Selecting a map loads that map's JSON from this folder if it is there, otherwise the browser save.
Export writes the card as map-mortar-card.json.
Load file opens a JSON file. The file's own map name is checked. A Bakurani card will not load while Ozeti is selected.

Sheet controls
Drag to pan. The wheel zooms on the cursor. The white circle is the combat area for that map's fixed diameter.
